# Коннектор Claude для Apex

Claude в claude.ai (в браузере и в приложении на телефоне) может ставить задачи и напоминания, менять программу тренировок, добавлять привычки, цели и вес. Изменения сразу появляются в открытом приложении.

## Настройка (один раз)

1. **Таблица ключей.** Supabase → SQL Editor → New query → вставить `supabase/claude-connector.sql` → Run.
2. **Функция.** Supabase → Edge Functions → Deploy a new function → Via Editor.
   Имя функции: `apex-mcp`. Вставить весь файл `supabase/functions/apex-mcp/index.ts` → Deploy.
   Затем в настройках функции выключить **Verify JWT** (Claude не присылает токен Supabase, доступ проверяется по ключу в ссылке).
   Через CLI то же самое: `supabase functions deploy apex-mcp --no-verify-jwt`.
3. **Ссылка.** В приложении: Настройки → Аккаунт → Claude → «Подключить Claude» → «Скопировать ссылку».
   Ссылка показывается один раз. Если потерялась, нажми «Новая ссылка».
4. **claude.ai.** Настройки → Коннекторы → Добавить свой коннектор (Add custom connector).
   Название: Apex, URL: скопированная ссылка → Добавить. В чате включи коннектор через кнопку инструментов.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `planner_overview` | задачи на ближайшие дни, привычки, цели, программа, вес, цели по КБЖУ |
| `list_tasks`, `add_tasks`, `update_task`, `delete_task` | задачи и напоминания (задача со временем) |
| `get_program`, `set_program` | программа тренировок: дни, дни недели, упражнения с комментариями, правила, недельный объём |
| `get_workouts` | записанные тренировки, чтобы Claude мог разобрать прогресс |
| `add_habit`, `delete_habit`, `add_goal`, `log_weight` | привычки, цели, вес |

## Безопасность

Ссылка содержит личный ключ: кто её знает, тот может менять твои данные в планере. В базе хранится только SHA-256 ключа.
«Новая ссылка» отключает старую, «Отключить» удаляет ключ совсем.
Функция работает с service-ключом Supabase, но каждый запрос ограничен пользователем, которому принадлежит ключ.

## Ограничения

- Работает только с аккаунтом Apex (вход по почте). Режим артефакта claude.ai хранит данные отдельно, коннектор их не видит.
- Задача со временем видна в планере, но пуш-уведомление в это время приложение пока не присылает.
- Если приложение было офлайн и правило тот же месяц задач, что и Claude, при синхронизации победит то, что сохранено позже.
